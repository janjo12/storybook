## HIG/Material Design Elements
- HIG says that you should group related items using (for example) negative space, colors, or shape; it also says controls should look distinct from content, that components should be aligned to ensure clean lines, and that they should be grouped in logical sections with control large enough to navigate (https://developer.apple.com/design/human-interface-guidelines/layout). My app's main screen divides the content into two sections, the scene exposition and the options for moving the story forward, with the options grouped as large, identical buttons so that the sections feel distinct and the buttons feel naturally grouped. The screen's elements are all aligned with each other.
- Material Design says that color should be used to indicate interactivity and that text should be legible on colored backgrounds (https://m2.material.io/design/color/the-color-system.html#color-usage-and-palettes). My app uses colors that stand out (dark colors for light mode, and light colors for dark mode) to indicate buttons, with text color on solid buttons that match (oppositely colored) screen backgrounds to be easily read.
